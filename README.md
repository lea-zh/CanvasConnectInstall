# CanvasConnect

Mac app that connects Claude or Codex to your Figma canvas.

## Install

1. Download [CanvasConnect.dmg](CanvasConnect.dmg) (click **View raw** or the download button on the file page).
2. Open the .dmg and drag **CanvasConnect** into your **Applications** folder.
3. Double-click CanvasConnect in Applications. A setup window walks you through the steps (two to five minutes).

If macOS refuses to open it, go to **System Settings > Privacy & Security**, scroll down, click **Open Anyway** next to CanvasConnect, then open it again.

## What you need

- Claude Desktop, or OpenAI's Codex app
- Figma Desktop (only for the Figma Console MCP option)

The .dmg includes a **READ ME FIRST** file covering what the app changes on your Mac and how to remove it.
